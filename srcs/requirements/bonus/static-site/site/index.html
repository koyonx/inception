42 · System Administration

Inception

A small infrastructure of independent containers, built from scratch, served behind a single TLS entrypoint.

Mandatory services

  • nginx

    The only door in. Port 443, TLSv1.2 / TLSv1.3 only, self-signed certificate.

  • wordpress

    php-fpm listening on 9000, no web server inside. Installed and configured by wp-cli at first boot.

  • mariadb

    Database on 3306, never published on the host. Bootstrapped from docker secrets.

Bonus services

  • redis

    Object cache for WordPress.

  • ftp

    vsftpd on the website volume.

  • adminer

    Database client at /adminer/.

  • static-site

    This page — HTML and CSS, no PHP.

  • backup

    Nightly database dumps, kept on their own volume.

Persistence

Two named volumes hold the state: one for the database, one for the website files. Both live under /home/<login>/data on the host, so destroying every container leaves the site intact.

Served by its own nginx container, proxied by the main one.
